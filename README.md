# robot_arm_v1
Robot Arm 1 


This repository documents all the parts desgined for Robot Arm 1 and all the code written for Robot Arm 1. 
For a connection guide reference the schematic found in the repositoy 'Schematic_Robot_Arm'
    
    
    IMPORTANT: Make sure to use an external power source, DO NOT  USE THE ARDUINO 5V OUTPUT, the 5 servos consume too much current resulting in faulty PWM signals readings.

    
How to use the scripts:

i. Complile the sketch in Arduino IDE and upload to the Arduino Mega 2560


ii. Run the python script


iii. In the python GUI, look for COM3 and connect to it.


    Note: at this step; if you have not used an external power source the python script will not be able to communicate with the Arduino
